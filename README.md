# 色谱批次核算台

把仪器导出的色谱峰表与进样序列核算成带证据的组分浓度。实验员可以在浏览器查看峰的归属、校准曲线和质控经过，封存可交付结果，并用同方法的另一批结果复核差异。

## 本地运行

在仓库根目录使用 Python 3.11 或更新版本启动。服务和前端运行时无需第三方依赖。

```sh
python3 -m chromaledger
```

浏览器打开 `http://127.0.0.1:8773/`。默认 SQLite 文件为 `.chromaledger/batches.sqlite3`。可以用 `--db` 指定文件，或用 `--port` 改端口。程序用于本机实验台，服务默认绑定回环地址。

## 操作步骤

1. 在批次目录点击「打开样例」可直接载入演示数据。要验证上传流程，点击「导入批次」，上传 `examples/peak-series.json`，或同时上传 `examples/instrument-sequence.json` 与 `examples/instrument-peaks.csv`，然后点击「预检」和「确认导入」。
2. 从批次目录打开记录，在进样列表点选一行。峰图显示实测保留时间、校正前后的窗口和候选峰。曲线视图显示各组分的标准点，质控时间线显示空白与核查样的结果。
3. 在交付视图封存可交付结果。JSON 和 CSV 随批次保存，可重算并核对 JSON 的 SHA-256。
4. 在同方法的第二个批次中调整一个样品的稀释倍数，使用独立批次 ID 导入。在交付视图选择另一批次，即可按样品、进样、组分查看变化。
5. 两台仪器测复核样时，可在交付视图的「分样清单互换判定」登记一版清单：列出每份母样两侧的进样、允许的对应关系及其出处。选定清单版本后，按组分给出超差对数的最少到最多，以及可确认互换、可确认不可换或证据不足的结论。新的交接凭据可登记为续版以排除某些对应；旧版仍可原样回查。

演示样例含 13 次进样、2 个组分、4 项可交付结果和 4 项暂缓结果。S-01 的组分甲实测为 3 mg/L，按两倍稀释还原后为 6 mg/L。规范化输入、进样证据和封存件均可通过本机 API 读取，接口见 [产品规格](PROJECT_SPEC.md)。

## 验证

```sh
python3 tools/buildcheck.py
python3 tools/smoke.py
python3 -m tools.check_store .chromaledger/batches.sqlite3
```

语法检查还需要 Node.js 18 或更新版本。冒烟脚本启动独立的本机临时服务和 SQLite 文件，从公开入口检查真实产品操作。数据库核验命令以只读方式检查结构、外键、输入摘要、核算结果与封存件。系统化测试套件留待后续补充。
